# 브라우저 테스트 항목 목록

테스트케이스.md 를 바탕으로 브라우저 조작으로 확인할 수 있는 항목을 뽑아 정리한 것입니다.
CSRF 보호(1.5)나 잘못된 HTTP 요청(1-6-2, 2-5-6)처럼 브라우저 조작만으로는 재현하기 어려운 항목은 제외했습니다.
