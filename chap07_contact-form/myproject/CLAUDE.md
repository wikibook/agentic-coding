# 문의 폼

## 프로젝트 개요
Laravel로 만드는 문의 폼.

## 기능
엔드유저가 입력하는 '문의 폼'과 관리자가 확인하는 '관리 페이지'로 구성된다.

### 문의 폼
- '이름' '이메일 주소' '제목' '본문'을 입력해 전송한다.
- 전송 전 '확인 화면' 있음
- 전송 후에는 '문의해 주셔서 감사합니다' 출력

### 관리 페이지
- 문의 목록을 표시한다
- 목록에서 클릭하면 상세가 표시된다
- 상태 관리 기능이 있다. '신규' '대응 중' '해결 완료'의 3단계를 드롭다운 리스트로 변경할 수 있다

## 기술 스택
- Laravel(PHP)
- 데이터베이스: SQLite

## 코딩 규약
- PSR-12 준수
- 주석은 한국어
