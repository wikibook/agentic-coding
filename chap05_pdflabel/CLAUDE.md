# PDF 라벨 메이커

## 프로젝트 개요
텍스트를 입력해 라벨 용지에 맞춘 PDF를 생성하는 웹 애플리케이션.

## 기술 스택
- HTML + JavaScript(서버 불필요, 브라우저만으로 동작)
- PDF 생성에는 jsPDF 라이브러리를 쓴다(CDN에서 읽어 들인다)
- 한국어 폰트는 NotoSansKR을 CDN에서 읽어 들여 jsPDF에 등록해 사용한다

## 라벨 사양
- 용지 크기: A4(210mm × 297mm)
- 여백(상하좌우)을 설정할 수 있다(기본값: 각 10mm)
- 라벨 크기(너비×높이)를 설정할 수 있다(기본값: 70mm × 37mm)
- 라벨 사이 여백을 설정할 수 있다(기본값: 2mm)
- 라벨 내 여백(패딩): 2mm
- 행 수·열 수는 용지 크기·여백·라벨 크기·라벨 사이 여백으로 자동 계산한다
- 각 라벨의 둘레에 테두리선(괘선)을 그린다
- 텍스트를 입력해 모든 라벨에 같은 내용을 인쇄한다

## 텍스트 표시 사양
- 텍스트 배치: 왼쪽 위 정렬
- 텍스트가 라벨 너비를 넘으면 자동으로 줄바꿈한다
- 여러 줄 텍스트에 대응한다
- 폰트 크기는 사용자가 지정할 수 있다(기본값: 10pt)

## PDF 출력 사양
- 생성한 PDF는 브라우저의 새 탭에 표시한다

## 코딩 규약
- JavaScript의 변수명·함수명은 카멜 케이스(camelCase)를 쓴다
- 주석은 한국어로 쓴다
- 하나의 HTML 파일로 모은다(외부 CSS나 외부 JS 파일은 만들지 않는다)
- 라벨 용지 프리셋 데이터는 labellist.js로 외부화한다(file://로 직접 열 수 있도록 .json이 아니라 .js로 하고, `const labelList = [...]` 로 정의해 `<script src="labellist.js">` 로 읽어 들인다)
